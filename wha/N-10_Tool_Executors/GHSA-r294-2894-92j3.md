### Basic Identification and Classification

- **1. Vulnerability Name**: Stored XSS in exported session HTML viewer via markdown/raw-HTML rendering
- **2. Vulnerability Identifier (CVE/GHSA)**: `GHSA-r294-2894-92j3`; no confirmed CVE assignment
- **3. CWE Classification**: `CWE-79` (Improper Neutralization of Input During Web Page Generation ('Cross-site Scripting')) [source: GitHub Global Advisory, GitHub Repository Advisory]
- **4. Affected Component**: Affected package(s): `openclaw` (npm).
- **5. Trust Boundary Crossing**: Not separately characterized as a structured trust-boundary field by the official advisory.

### Root Cause and Trigger Conditions

- **6. Vulnerability Summary**: The exported session HTML viewer allowed stored XSS when untrusted session content included raw HTML markdown tokens or unescaped metadata fields.
- **7. Technical Root Cause**: The exporter rendered markdown with `marked.parse(...)` and inserted HTML via `innerHTML`, but did not override the `html` renderer token path. Raw HTML (for example `<img ... onerror=...>`) was passed through. Additional tree/header metadata fields were interpolated without escaping in the export template.
- **8. Architectural/Design Root Cause**: Not separately characterized by the official advisory. See fields 5 and 7 for the published boundary and technical details.
- **9. Trigger Prerequisites**: The exported session HTML viewer allowed stored XSS when untrusted session content included raw HTML markdown tokens or unescaped metadata fields.

### Severity and Impact

- **10. CVSS Score and Vector**: GitHub Global Advisory CVSS v4.0: **5.3 Medium** (`CVSS:4.0/AV:N/AC:L/AT:N/PR:N/UI:P/VC:N/VI:N/VA:N/SC:L/SI:L/SA:N`); GitHub Repository Advisory qualitative severity: **Medium**
- **11. Required Attacker Privileges**: `PR:N` (None), according to GitHub Global Advisory CVSS v4.0.
- **12. Direct Impact**: Opening a crafted exported HTML session could execute attacker-controlled JavaScript in the viewer context. This can expose session content in the page and enable phishing or UI spoofing in the trusted export view.
- **13. Chained/Indirect Impact**: No separate chained or indirect impact is published by the official advisory.

### Code and Remediation

- **14. Vulnerable Code Snippet**: Removed lines from the published fix patch in `src/auto-reply/reply/export-html/template.js` at [`f8524ec77a39`](https://github.com/openclaw/openclaw/commit/f8524ec77a3999d573e6c6b8a5055bf35c49a2e6):

  ```diff
  -          return labelHtml + `<span class="tree-role-tool">[${msg.toolName || "tool"}]</span>`;
  -        return labelHtml + `<span class="tree-muted">[${msg.role}]</span>`;
  ```
- **15. Fix Patch (Commit)**: Specific fix commit(s) published by the advisory: [`f8524ec77a3999d573e6c6b8a5055bf35c49a2e6`](https://github.com/openclaw/openclaw/commit/f8524ec77a3999d573e6c6b8a5055bf35c49a2e6) - [PATCH] fix(security): harden exported session html rendering.

  Fix excerpt from `src/auto-reply/reply/export-html/template.js`:

  ```diff
  +          return labelHtml + `<span class="tree-role-tool">[${escapeHtml(msg.toolName || "tool")}]</span>`;
  +        return labelHtml + `<span class="tree-muted">[${escapeHtml(msg.role)}]</span>`;
  ```
- **16. Fix Summary**: Added a `marked` `html(token)` renderer override that escapes raw HTML tokens. Escaped previously unescaped tree/header metadata fields in the export template. Added image MIME sanitization for exported data-URL image rendering. Added regression tests for markdown/token and metadata escaping paths.
