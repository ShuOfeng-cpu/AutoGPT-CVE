## 1. Overview

AutoGPT_CredentialLeak_01 Vulnerability Report We discovered a Credential Leakage vulnerability in the AutoGPT project. Overview Vulnerability Type: Credential Leakage Affected Location: classic/forge/forge/components/git_operations/git_operations.py:102 Trigger Scenario: clone_repository sends configured GitHub credentials to attacker-controlled URLs

## 2. Technical Details

### 2.1 Root Cause

The issue is rooted in insufficient validation or authorization in GitHub credentials (`classic/forge/forge/components/git_operations/git_operations.py`). AutoGPT_CredentialLeak_01 Vulnerability Report We discovered a Credential Leakage vulnerability in the AutoGPT project. Overview Vulnerability Type: Credential Leakage Affected Location: classic/forge/forge/components/git_operations/git_operations.py:102 Trigger Scenario: clone_repository sends configured GitHub credentials to attacker-controlled URLs

### 2.2 Affected Code

The advisory identifies the following affected file(s):

- `classic/forge/forge/components/git_operations/git_operations.py`

### 2.3 Exploitation Path

Attackers may obtain credentials, tokens, internal metadata, or confidential business data and reuse them for further compromise. Remediation Never inject secrets into arbitrary user-provided clone URLs. Restrict clone targets to trusted GitHub hosts. Use secure credential mechanisms (helper/askpass/per-host auth config) instead of URL credentials.
