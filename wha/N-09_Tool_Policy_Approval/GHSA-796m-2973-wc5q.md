### Basic Identification and Classification

- **1. Vulnerability Name**: exec allowlist/safeBins policy-runtime mismatch via env -S wrapper interpretation
- **2. Vulnerability Identifier (CVE/GHSA)**: `GHSA-796m-2973-wc5q`; no confirmed CVE assignment
- **3. CWE Classification**: `CWE-436` (Interpretation Conflict) [source: GitHub Global Advisory, GitHub Repository Advisory]
- **4. Affected Component**: Affected package(s): `openclaw` (npm).
- **5. Trust Boundary Crossing**: Not separately characterized as a structured trust-boundary field by the official advisory.

### Root Cause and Trigger Conditions

- **6. Vulnerability Summary**: `tools.exec` allowlist/safe-bins evaluation could diverge from runtime execution for wrapper commands using GNU `env -S/--split-string` semantics. This allowed policy checks to treat a command as a benign safe-bin invocation while runtime executed a different payload.
- **7. Technical Root Cause**: Root cause was policy/runtime interpretation mismatch for dispatch wrappers: analysis resolved an effective executable from wrapper-unwrapped argv, execution could still run original wrapper argv semantics, safe-bin short-flag handling also allowed unknown short options in clusters.
- **8. Architectural/Design Root Cause**: Not separately characterized by the official advisory. See fields 5 and 7 for the published boundary and technical details.
- **9. Trigger Prerequisites**: `tools.exec` allowlist/safe-bins evaluation could diverge from runtime execution for wrapper commands using GNU `env -S/--split-string` semantics.

### Severity and Impact

- **10. CVSS Score and Vector**: GitHub Global Advisory CVSS v4.0: **5.7 Medium** (`CVSS:4.0/AV:L/AC:L/AT:P/PR:L/UI:N/VC:N/VI:H/VA:N/SC:N/SI:N/SA:N`); GitHub Repository Advisory qualitative severity: **High**
- **11. Required Attacker Privileges**: `PR:L` (Low), according to GitHub Global Advisory CVSS v4.0.
- **12. Direct Impact**: An attacker able to influence tool command text (for example via untrusted prompt/content injection reaching an exec-capable flow) could bypass allowlist/safe-bins intent and execute unexpected commands.
- **13. Chained/Indirect Impact**: No separate chained or indirect impact is published by the official advisory.
